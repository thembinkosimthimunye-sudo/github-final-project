# Simple Interest Calculator

A simple, user-friendly web application designed to calculate simple interest based on principal amount, annual interest rate, and time period in years.

## Formula Used
The application uses the standard simple interest formula:
$$\text{Simple Interest} = \frac{P \times R \times T}{100}$$

Where:
* **P** = Principal amount
* **R** = Annual interest rate (in %)
* **T** = Time period (in years)

## Features
* **Real-time Calculation:** Instantly computes interest upon input.
* **Responsive Design:** Works flawlessly on both mobile devices and desktops.
* **Input Validation:** Prevents negative numbers or invalid entries.

## How to Use
1. Enter the initial **Principal Amount** you wish to invest or borrow.
2. Input the **Annual Interest Rate** percentage.
3. Enter the total **Time Period** in years.
4. View the calculated simple interest and final total balance instantly.
